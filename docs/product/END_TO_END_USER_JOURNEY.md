# End-to-End User Journey v0.4.0

## 1. 首次配置

```text
Add Relay URL + Key
→ Test Endpoint
→ Add/Discover Models
→ Probe Capabilities
→ Select Defaults
```

## 2. Tools

```text
Enable Built-in Tools
→ Add MCP/REST Integration
→ Review permissions
→ Test/Approve
```

## 3. Team

```text
Choose Lean/Standard/Rigorous
→ inspect Roles
→ assign per-Agent models
→ set budget/autonomy
```

## 4. Project

```text
Objective
Target Profile
Inputs
Data classification
Deliverable type
```

## 5. Dry Run

系统展示：

- 实际 Role/Agent；
- 每个模型；
- Tools/permissions；
- Workspace/Compute；
- budget estimate/reservation；
- approvals；
- risks。

## 6. Execute

用户看到：

```text
Run Timeline
Tasks
Agent Sessions
Tool Calls
Workspace Diffs
Experiments
Costs
Gates
```

## 7. Intervention

Pause、Approve、Reject、Fork、降低预算、替换未来 Task 的 Agent。

## 8. Finish

```text
Claims/Evidence
Experiments
Review Findings
Deliverables
Audit
Reproducibility Bundle
```

## 9. Archive/Reuse

将 verified findings、negative results 和 lessons 经 Memory Gate 写入 Project Memory。
