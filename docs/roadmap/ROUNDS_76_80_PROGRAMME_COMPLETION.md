## 5. 方法论收获（跨轮复用）

1. **「让声明生效」与「重新发明合法集」是两件事**：把出厂策略里已声明的键判成非法 ⇒
   真实控制面 FAIL。判据方向应是「既有声明被同一条线读」，不是「我认为只有三个键合法」。
2. **定向套件绿 ≠ 全量绿**：规模门（50 行函数 / 450 行文件）与旧轮次的逐字锚点**只有
   全量 m0 抓得到**。序 80 因此付了两次全量 m0 的代价。
3. **见证绑定的是跑门那一刻的树**：任何记录改动都会让上一次终态行失效 ⇒ 健康顺序是
   「写记录 → 记录面判据 → **最后**跑 m0 → 不再改树 → 提交」。
4. **台账不许空真**：`## CI 台账` 为空 ⇒ 判据失去对象 ⇒ 两个 `quality-*` job 必红。
   这不是噪声，是「未取证 ≠ 通过」。
5. **判据的射程要写进判词**：`live_run_gate` 判**可解析**不判**有效**；面板判词判
   「句子存在」不判「论证成立」；消融判「分布位移」不判「采纳」。

并被逐条登记（`W-1`/`W-2`/`U-1`/`U-2`/`R-1`/`R-2`）。
