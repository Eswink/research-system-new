# Run State Machine v0.4.0

状态集合与迁移表是 v0.4.0 明确规格；实现位于 `packages/domain/state_machines.py`，测试位于 `tests/domain/test_state_machines.py`。terminal 状态默认不可回退。

## ResearchRun

```text
DRAFT
→ COMPILING
→ PREFLIGHT
→ READY
→ RUNNING
↔ WAITING_FOR_APPROVAL
↔ PAUSED
→ DEGRADED
→ SUCCEEDED
→ FAILED
→ CANCELLED
```

## Cancellation 子状态机

```text
REQUESTED → COOPERATIVE
REQUESTED → FORCED → COMPENSATING → CANCELLED
```

Terminal: CANCELLED。

## Transition Rules

- `RUNNING` 前必须有 PASS Preflight 和 frozen Manifest；
- `SUCCEEDED` 前必须满足 Task/Phase acceptance criteria；
- `FAILED` 不等于科学负结果；
- 运行中改变关键依赖需 Manifest Revision/Fork；
- terminal state 默认不可回退。
