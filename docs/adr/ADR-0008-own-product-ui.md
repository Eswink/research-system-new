# ADR-0008 — Own the Research Product UI

Status: Accepted

Do not base product architecture on an upstream coding-agent UI.

Reasons:

- OpenHands standalone Agent Canvas repo has already been archived/migrated.
- coding-oriented schemas differ from research product entities.
- Research Map / Evidence / Experiments / Target Profile are our differentiators.

Use Next.js owned UI; reuse UX patterns, not upstream internal state.
