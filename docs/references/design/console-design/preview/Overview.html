Design principles · non-negotiable
P1
Preflight before execute
Start disabled when Preflight ≠ PASS. Findings translate machine codes into human fixes.
P2
Evidence-native
Every claim carries status. PROPOSED renders as dashed/faded — never same weight as VERIFIED.
P3
Model drift visible
Request vs returned model name shown. If provider hides fingerprint, we say "Configuration reproducible".
P4
UNKNOWN ≠ zero
Null cost, missing probes, absent fingerprints render as UNKNOWN. Never faked as 0 or a placeholder.
P5
Deny by default
Every high-risk approval shows consequence preview. No "approve all", no "skip preflight".
