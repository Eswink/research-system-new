# v0.2.1 → v0.2.2 Migration

## 不变

- 用户 LLM 中转站；
- per-Agent model；
- OpenHands Native Runtime；
- Tool/Skill/Capability；
- MCP/REST Tools；
- Workspace/Sandbox；
- Evidence/Evaluation；
- 26 个 Role。

## 新增

```text
CompiledRunPlan / Preflight
ResearchTask / TaskContract / HandoffBundle
TeamTemplate / RoleActivationPolicy
ModelCompatibility / RuntimeFingerprint
BudgetReservation / UsageLedger
TaskLease / Idempotency / Outbox
MemoryWriteProposal
ToolPack supply-chain
Autonomy/Gates
Artifact lifecycle
Deployment profiles
Observability privacy
```

## Compatibility

v0.2.1 的 Role/Agent/Model config 可以迁移；默认：

- TeamTemplate = CUSTOM；
- Autonomy = GUARDED_AUTONOMOUS；
- 未 Probe 的模型状态 = UNKNOWN；
- 旧 Run 只读保留，不补造 RuntimeFingerprint。
