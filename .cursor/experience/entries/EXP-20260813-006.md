# Read 工具读取目录路径失败时改用 Ls 列出目录

## Problem

- 现象：对目录路径调用 `Read` 工具返回错误 `Path is a directory, not a file`，无法获取目录内容。
- 上下文：规划/侦察阶段需要查看 `packages/domain`、`.cursor/plans/tasks` 等目录结构时触发；本会话发生 2 次。
- 影响：阻塞目录内容侦察，需要改用其他工具完成同样目标。

## Solution

- 根因：`Read` 只接受文件路径，不处理目录；对目录的语义是列出子项，应由 `Ls` 承担（单次观察，未经独立复现；本会话 2 次复现）。
- 解法：需要目录结构时直接使用 `Ls`（可传 `ignore` 过滤 node_modules/.git 等大目录），不要用 `Read` 读目录，也不要改用 `Glob("*")` 递归列出整个目录（有明确工具说明要求 Ls 优先）。
- 被拒方案：`Glob` 递归匹配目录内容会返回过量结果，不适合简单目录列举。

## Evidence

- source_refs：本会话中 `Read` 对 `d:\research-system\packages\domain` 与 `d:\research-system\.cursor\plans\tasks` 两次返回 `Path is a directory, not a file`，随后 `Ls` 均成功列出内容。
- 如何失效：若工具语义变更（`Read` 支持目录）或出现新的目录列举工具，本条不再适用。
