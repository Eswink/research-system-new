# Windows PowerShell 下命令写法：`;` 分隔、`git commit -F`、cmd 开关需 `cmd /c` 包裹

## Problem

- 现象 1：两条 git 命令在 PowerShell 下直接报 ParserError（`标记"&&"不是此版本中的有效语句分隔符`；`重定向运算符后面缺少文件规范`）。M6 复审会话再次复现：`git log --oneline -15 && git status --short | head -30` 报同一 ParserError。
- 现象 2：`dir /b <path>` 报 `找不到路径"D:\b"，因为该路径不存在`——cmd 的 `/b` 开关被 PowerShell 当作 `D:\b` 路径参数解析。
- 上下文：`git status --short && git log --oneline -8`、`git commit -m "$(cat <<'EOF' ...)"`、`dir /b <dir>`；Windows PowerShell 5.x。
- 现象 3（M8 会话，2026-08-14）：`uv run python -c "import asyncio; ...; async def main(): ..."` 报 SyntaxError（分号链后 `async def` 非法）——PowerShell 下内联多语句/async 探测代码不可靠。
- 现象 4（M9 会话，2026-08-15）：`uv run python -B -c` 命令内部再嵌套多层引号（`python -c` 套 `python -c`）报 ParserError（参数列表中缺少参量）；`git diff --cached | rg -n "<长正则含引号>"` 同样报 ParserError——PowerShell 把整个 command 包进临时 ps-script 双重解析，嵌套引号直接破坏语法。
- 影响：多命令串联、长 commit message、目录列举失败，阻塞提交流程与文件系统操作（现象 1 累计 3 次、现象 2 累计 2 次独立失败，同根因家族）；现象 3 阻塞 Python 探测冒烟；现象 4 阻塞容器冒烟与 secret 扫描（各 1 次）。

## Solution

- 根因：PowerShell 不兼容 bash 的 `&&` 串联、`<<'EOF'` heredoc 与 cmd 的 `/x` 开关语法；单次观察 + 权威依据（PowerShell 语法规范），未经独立复现。
- 解法：
  1. 多命令串联改用 `;`：`git status --short; git log --oneline -8`（本会话后续多次成功）。
  2. 长 commit message 改用 message 文件：先写 `commit-msg.txt` 再 `git commit -F <path>`；避免在命令行内嵌多行文本与引号嵌套。
  3. 目录列举用原生 `Get-ChildItem`；确需 `dir /b` 时用 `cmd /c "dir /b <path>"` 包裹（本会话成功路径）。
  4. 复杂 Python 探测/冒烟代码写入正式脚本或测试文件执行（`uv run python -B -m ...` 或 pytest 文件），`python -c` 只用于单行简单表达式（M8 会话成功路径：MCP 冒烟直接写入 tests/contracts/test_tool_provider_contract.py）。
  5. 任何含引号嵌套的命令（多层 `-c`、长正则、内联 JSON）不直写 PowerShell command：探测代码落临时脚本文件（M9 会话成功路径：`.m9-smoke.py` 执行后删除）；管道正则扫描用简化模式或脚本文件（M9 会话成功路径：secret 扫描正则去引号后重跑通过）；对已变更文件的模式扫描优先改用 Grep 工具（ripgrep 工具，`path` 指向变更目录 + 正则 pattern 参数），完全绕过 PowerShell 管道与引号解析（M10 会话成功路径：`git diff --cached | rg` 多模式 secret 正则 ParserError 后改 Grep 工具命中 4 处测试 fixture）。
- 被拒方案：`&&` 串联（ParserError）；heredoc 内嵌 `$(cat <<'EOF')`（ParserError）；裸 `dir /b`（`/b` 解析为 `D:\b` 路径错误）。

## Evidence

- source_refs：本会话终端输出（ParserError 两处、`找不到路径"D:\b"` 一处）；本会话成功路径 `git commit -F`（提交 1035a64、c31c8b7）、`cmd /c "dir /b /s ..."`（M5R 复审会话 agent-server 定位）；`.cursor/rules/42-command-encoding.mdc`（"只有确认当前 shell 支持时才使用 &&"约束）。
- 如何失效：切换到 bash/zsh 终端时本条目不适用（`&&`、heredoc、`dir /b` 均合法）；git 或 PowerShell 行为变化时需复核。
