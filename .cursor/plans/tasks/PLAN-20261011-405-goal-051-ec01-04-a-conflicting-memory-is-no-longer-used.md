## 决策登记（本 cycle 落定）

| # | 决策 | 结论与依据 |
| --- | --- | --- |
| ① | 「有冲突」怎么进处置 | **取「新增第五态 `CONFLICTED`」** —— 要求是「与四态**可区分**」；复用 `ANNOTATE` 会让两者共用一格，判词只能靠措辞区分（**那正是轴的反面**）|
| ② | 消费端落点 | **取「与 `ANNOTATE` 同类：执行但带标注」** —— 冲突**不等于不可用**；「未消解」是**要人看**，不是「不许用」（与 `SKIP` 的「不参与后续行为」区分开）|
| ③ | 优先级 | **固定**：`CONFLICTED` **先于**时效（与序 18 的「已取代先于时效」同一形态），但不与「已取代」抢 —— 两者并存时以**取代**为先（「已不是当前版本」比「有冲突」更根本）；**逐条判据钉住** |
| ④ | 是否动 DTO | **不动**：本轮改的是**编排消费面**的读面（`memory.read`）；HTTP 读面**未**披露（`W-4` 类未覆盖）⇒ **无需**重生成快照 |
| ⑤ | 承接面 | **不动**（复用既有声明 / 落库 / 披露 / 处置纯函数 / 消费端分派形态）|
